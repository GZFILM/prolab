# ProLab · by G.Z MOTION LAB

אפליקציה לטאבלט, לטלפון ולמחשב: פירוק תסריט, שוטים וסטוריבורד, לו"ז צילום, מצב סט, Whisky Shot והצעות לעריכה.

**כתובת:** https://gzfilm.github.io/prolab/

## התקנה בטאבלט אנדרואיד
1. פותחים את הכתובת ב-Chrome.
2. תפריט ⋮ ואז "הוסף למסך הבית" / "התקן אפליקציה".

## חיבור ל-Claude
בהגדרות בוחרים:
- **ידני דרך claude.ai**: מעתיקים בקשה לשיחה ומדביקים את התשובה. כלול במנוי.
- **אוטומטי עם מפתח API** מ-console.anthropic.com. המפתח נשמר רק במכשיר.

## איפה הנתונים
הפרויקטים ותמונות הרפרנס נשמרים רק במכשיר (IndexedDB). להעברה בין מכשירים: עריכה ← "שמור גיבוי" / "פתח גיבוי".

## מבנה
קבצים סטטיים בלי שלב בנייה: `index.html`, `styles.css`, `app.js`, `sw.js` (עבודה בלי אינטרנט), `manifest.webmanifest`, `vendor/` (Anthropic SDK, mammoth ל-Word, pdf.js ל-PDF).
בכל שחרור מעלים את `VERSION` ב-`sw.js`.
